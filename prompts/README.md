# Prompts para o Fable

Como usar:
1. Abra uma sessão do Claude Code com o modelo **Fable** neste repositório.
2. Cole o prompt da fase atual (`fase-N.md`).
3. Quando ele terminar, teste no tablet/web seguindo as instruções que ele der.
4. Se algo estiver errado, descreva o que você vê, com print se puder (ex.: "o traço some quando levanto a caneta"). Use `ajustes.md` como modelo.
5. Só passe para a próxima fase quando os critérios de **Aceite** de `docs/06-roteiro.md` estiverem ok.

Dica: uma sessão nova por fase deixa o contexto limpo. O `CLAUDE.md` e os `docs/` garantem que ele saiba de tudo.
