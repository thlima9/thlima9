# Prompt — Correções e ajustes

```
Leia o CLAUDE.md. Estou na Fase N.
Problema: <o que você fez> → <o que aconteceu> → <o que esperava>.
Onde: tablet / web / ambos.
(Anexe print ou vídeo se possível.)
Investigue a causa, corrija sem quebrar o resto, adicione um teste se fizer sentido e me diga como confirmar a correção.
```

Exemplos de descrição:
- "Escrevo rápido e a linha fica com cantos, não é suave."
- "Na web o traço aparece mais grosso que no tablet."
- "Fiquei sem internet, escrevi 3 páginas, voltei e elas não apareceram na web."
